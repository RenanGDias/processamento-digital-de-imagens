┌─ CANNY CLÁSSICO (Escalar) ────────────────────────────────────────────────────┐
│                                                                               │
│  RGB Image                                                                   │
│      ↓                                                                       │
│  Convert to Gray (linear: 0.299R + 0.587G + 0.114B)                        │
│      ↓                                                                       │
│  Gaussian Blur (σ = 1.0)                                                   │
│      ↓                                                                       │
│  Sobel Gradients (magnitude + direction)                                   │
│      ↓                                                                       │
│  Non-Maximum Suppression (NMS) → afina bordas                              │
│      ↓                                                                       │
│  Hysteresis Thresholding (T_low=100, T_high=200)                           │
│      ↓                                                                       │
│  Binary Edge Map (1 pixel de largura)                                     │
│                                                                               │
│  ⚠️  PROBLEMA: Perde bordas cromáticas (ex: Vermelho ↔ Azul em cinza)      │
│                                                                               │
└───────────────────────────────────────────────────────────────────────────────┘


┌─ CANNY MODIFICADO (Vetorial - Gabor-Di Zenzo) ────────────────────────────────┐
│                                                                               │
│  RGB Image (SEM conversão para cinza)                                       │
│      ├──→ Di Zenzo Operator                                                │
│      │       • Lê canais R, G, B                                           │
│      │       • Computa gradientes ∇R, ∇G, ∇B                              │
│      │       • Matriz de estrutura 2×2                                    │
│      │       • Autovalores/autovetores                                    │
│      │       → Magnitude do maior autovalor (contraste cromático)         │
│      │                                                                     │
│      ├──→ Gabor Filter Bank (24 filtros)                                  │
│      │       • 8 orientações (0° a 180°)                                 │
│      │       • 3 frequências (múltiplas escalas)                         │
│      │       • Envelope Gaussiano × Onda senoidal                        │
│      │       → Respostas de frequência/orientação                        │
│      │                                                                     │
│      └──→ Fusão (máxima energia + direção)                               │
│             NMS + Hysteresis                                              │
│                      ↓                                                    │
│  Binary Edge Map (preserva bordas cromáticas!)                            │
│                                                                               │
│  ✨ VANTAGEM: Detecta bordas invisíveis no Canny clássico                  │
│                                                                               │
└───────────────────────────────────────────────────────────────────────────────┘

═══════════════════════════════════════════════════════════════════════════════════
  🔧 CONFIGURAR PARÂMETROS
═══════════════════════════════════════════════════════════════════════════════════

Edite config/params.json para customizar:

  {
    "sigma": 1.0,                  ← Desfoque Gaussiano (↑ = mais suave)
    "kernel_size": 5,              ← Tamanho (3, 5, 7...)
    "low_threshold": 100,          ← Limiar baixo da histerese
    "high_threshold": 200,         ← Limiar alto da histerese
    "gabor_orientations": 8,       ← Orientações (4-16)
    "gabor_frequencies": 3         ← Frequências (2-5)
  }

Presets recomendados:
  • params.json           = Equilibrado (padrão)
  • params_sensivel.json  = Mais bordas (limiares baixos)
  • params_robusta.json   = Menos ruído (limiares altos)
