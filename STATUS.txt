🚀 PRÓXIMAS ETAPAS
───────────────────────────────────────────────────────────────────────────────

1️⃣  ADICIONAR IMAGENS AO DIRETÓRIO 'imagens/'
    - Coloque suas imagens de teste em: imagens/

2️⃣  EXECUTAR VIA TERMINAL (Lote)
    cd src
    python main.py --metodo both --config ../config/params.json

3️⃣  OU EXECUTAR VIA JUPYTER NOTEBOOK (Análise Interativa)
    jupyter notebook demo.ipynb
    (abrir em: http://localhost:8888)

4️⃣  VERIFICAR RESULTADOS EM 'resultados/'
    - [image]_canny_classic.png
    - [image]_canny_modificado.png
    - [image]_comparacao.png

🔬 CARACTERÍSTICAS PRINCIPAIS
───────────────────────────────────────────────────────────────────────────────

✓ Canny Clássico (Escalar)
  • Conversão RGB → Cinza
  • Desfoque Gaussiano
  • Gradientes Sobel
  • Supressão de Não-Máximos (NMS)
  • Histerese com 2 limiares

✓ Canny Modificado (Vetorial)
  • Processamento sem perda de cor (Di Zenzo)
  • Banco de Filtros de Gabor (24 filtros)
  • Preservação de bordas cromáticas
  • Fusão de informações no domínio das derivadas
  • NMS + Histerese final

✓ Tudo implementado "do zero" com NumPy
  ✗ SEM usar cv2.Canny, cv2.filter2D, cv2.getGaborKernel

💡 EXEMPLO DE USO
───────────────────────────────────────────────────────────────────────────────

# Via Python direto
import sys
sys.path.insert(0, 'src')
from canny_classic import CannyClassic
from utils import read_image, save_image

image = read_image('imagens/test.png')
detector = CannyClassic()
edges = detector.detect(image)
save_image(edges, 'resultados/test_edges.png')
